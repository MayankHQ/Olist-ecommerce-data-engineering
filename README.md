# Olist E-Commerce Data Engineering

A data engineering project built on Databricks, processing and analyzing the [Olist Brazilian E-Commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

## Overview

This project implements a data pipeline for the Olist e-commerce dataset, covering ingestion, transformation, and analytics.

## Tech Stack

* Databricks
* Apache Spark
* Delta Lake
* Unity Catalog
